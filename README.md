# 联通积分兑换 Skill

先登录中国联通官方积分商城，读取当前积分和可选商品，再由用户选择**流量包、语音包或影音组合**。Agent 负责比较、准备结算、按本笔授权提交及核对结果；登录和必要验证由本人在官网完成。

默认只办理本机、现金补款 0 元、无自动续订的权益。商品、积分价格、有效期和号码资格均以本次官网页面为准。不包含 PLUS。

## 安装与使用

```sh
git clone https://github.com/huntingrin/cucc-points-redeem.git
```

将整个仓库作为 `cucc-points-redeem` 文件夹放入宿主的技能目录，例如 Codex 的 `~/.codex/skills/`。也可让具备浏览器能力的 Agent 直接读取 [SKILL.md](SKILL.md)。

先查询可说：

> 用 $cucc-points-redeem 登录联通积分商城，查我的积分，列出可选的流量包、语音包和影音组合，先不兑换。

用户选定完整商品、数量及费用后，Agent 按授权继续办理。验证码直接填在官方页面，不发到聊天。验证后先判断是否已付款或生成订单，再决定是否提交，避免重复扣分。

## 运行要求

- 宿主具备浏览器导航、读取页面、填写和点击能力，并遵循其页面所有权、后台操作及人工交接规则。
- 本人在中国联通官网完成登录；复用有效会话，无需导出 Cookie。
- 可选的本地提交保护脚本使用 Python 3 标准库，文件锁依赖 macOS/Linux 的 `fcntl`。没有相应执行能力时，由 Agent 按同样规则维护私有断点。

脚本只记录计划、提交断点和核对结果，不控制浏览器、不读取短信、不执行兑换。运行状态保存在仓库外的私有任务目录。用法见[状态脚本说明](references/transaction-state.md)。

## 验证范围

2026-10-20 已在 Ego 浏览器实测登录、余额与商品读取、积分结算和验证码交接；一笔 1GB 日包订单完成，扣减 300 积分、现金 0 元。接回页面时已显示支付成功，Agent 最终支付按钮点击尚未实测；语音及影音尚未完成本机真实兑换。

交易状态脚本通过 14 项离线测试，覆盖费用变化、验证状态、成功页恢复、重复提交和并发提交保护；技能另经 48 项独立离线检查。离线检查不代表所有号码、商品或浏览器均已完成真实兑换。
